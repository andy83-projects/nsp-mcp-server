# Contributing

This project is a work in progress. Report the exact NSP/Windows versions, page/table identity, units, expected/actual behavior, and reproducible **offline** steps. Remove personal data, native maps, credentials, network addresses, and private logs. Describe whether an action might already have applied before a failure.

For code changes, build on Windows and run the logic tests. Document any live NSP checks separately from automated tests. New write paths need exact-target verification, audit preservation, interrupted-operation handling, and independent readback. Do not add blanket retries, clear recovery evidence, or treat missing validation text as proof of a valid map.

Keep private test data and build outputs out of Git. Use your own verified GitHub commit email or GitHub-provided noreply address. Do not use made-up shared addresses: GitHub can attribute them to an unrelated account. Do not add fabricated human or AI co-author trailers.

No repository license has been selected yet; discuss licensing/reuse with the owner before submitting material whose terms require a particular license. Third-party software keeps its own applicable terms. Dependency references do not make their authors contributors to this repository.
